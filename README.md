# ร่องรอยลับในข้อความ AI — AI ซ่อนลายน้ำในข้อความอย่างไร?

แอนิเมชันอธิบายแนวคิด 2D flat vector ความยาว 52 วินาที (16:9, 1920×1080, 30 fps) — storyboard ฉบับเต็มพร้อมพรอมป์ต์อยู่ใน [`STORYBOARD.md`](STORYBOARD.md)

| ฉาก | เวลา | เนื้อหา |
|---|---|---|
| 1 | 0–4 s | นักศึกษายื่นกระดาษให้หุ่นยนต์ AI |
| 2 | 4–26 s | กลไกลายน้ำ: AI ให้คะแนนคำถัดไป → กุญแจลับ + คำก่อนหน้า แบ่งคำเป็น 2 กลุ่ม → เพิ่มคะแนน “กลุ่มพิเศษ” เล็กน้อย → ทำซ้ำทุกคำ |
| 3 | 26–30 s | บัตรคำรวมเป็นข้อความ จุดม่วงกะพริบแล้วจางหาย |
| 4 | 30–34 s | คนอ่านเห็นข้อความธรรมดา |
| 5 | 34–41 s | เครื่องมือตรวจที่มีกุญแจเดียวกันนับคำกลุ่มพิเศษ เทียบกับระดับความบังเอิญ |
| 6 | 41–46 s | ข้อความสั้น / ถูกแก้ไข → สัญญาณอ่อนลงจนต่ำกว่าเกณฑ์ |
| 7 | 46–52 s | ลายน้ำเป็นจิ๊กซอว์หนึ่งชิ้นของหลักฐาน · “ไม่พบลายน้ำ ≠ ไม่ได้ใช้ AI” |

## ไฟล์
- `index.html` — ตัวแอนิเมชัน (SVG + JS) เปิดในเบราว์เซอร์ได้เลย มีปุ่มเล่น/หยุด แถบเลื่อนเวลา และสวิตช์เปิด/ปิดข้อความ
  - `?captions=0` ภาพเปล่าไม่มีข้อความ (สำหรับใส่ข้อความเองตอนตัดต่อ) · `?render=1` โหมดเรนเดอร์ 1920×1080
- `output/watermark-explainer.mp4` — ฉบับมีชื่อคลิป คำบรรยาย และข้อความประกอบ
- `output/watermark-explainer-clean.mp4` — ฉบับไม่มีข้อความ (clean plate) เว้นพื้นที่ด้านล่างสำหรับคำบรรยาย
- `scripts/render.js` — เรนเดอร์ MP4 ใหม่: `node scripts/render.js output/x.mp4 [--clean]` (ต้องมี Playwright + ffmpeg)
- `scripts/snap.js` — ถ่ายภาพนิ่ง ณ เวลาที่กำหนด: `node scripts/snap.js <dir> 2.0 12.8 27`

ยังไม่มีเสียงบรรยาย — ช่วงเวลาคำบรรยายอยู่ในตัวแปร `CAPS` ใน `index.html` ใช้เป็นจังหวะอัดเสียงได้
